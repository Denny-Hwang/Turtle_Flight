# 실기기 검증 (배포 전 필수)

작성 2026-11-22. 출시·가격 결정 전에 이 문서의 1–3단계를 끝낸다. 결과는 맨 아래
"결과 기록"에 남긴다. 다음 세션은 결과 기록부터 읽고 이어간다.

## 0. 막혀 있는 것 (오너만 할 수 있음)

**Xcode → Settings → Accounts 에 Apple ID 로그인.** 2026-11-22 확인 결과, iPhone XS 는
연결·페어링돼 있고 개발 인증서(`Apple Development: … (86WFBRY2ST)`)도 키체인에 있지만,
Xcode 에 계정이 없어 `com.turtleflight.app` 프로비저닝 프로파일을 만들 수 없다
(`error: No Accounts`). 로그인 후 아이폰에서 설정 → 개인정보 보호 및 보안 →
**개발자 모드** 를 켠다.

2026-11-23 재확인: iPhone XS(iOS 18.7.12) 유선 연결·페어링, **개발자 모드 켜짐**, 개발 인증서 있음.
서명 없는 기기 빌드(`-O`)는 통과(앱 22MB). 남은 것은 **Xcode 계정 로그인 하나**
(`xcodebuild` 가 아직 `No Accounts` / `No profiles for 'com.turtleflight.app'`).
같은 날 스크립트의 기기 찾기 버그(아이디 대신 `available` 을 잡던 것)를 고치고 `--no-scenes` 를 추가했다.

## 1. 자동 측정 + 장면 확인 (약 10분)

```bash
TEAM=AFQ4SC9L65 scripts/device/verify.sh             # 빌드 → 설치 → 3분 자동 비행 측정 → 장면 14개 순서대로 보기
TEAM=AFQ4SC9L65 SOAK=600 scripts/device/verify.sh    # 발열 확인용 10분
TEAM=AFQ4SC9L65 scripts/device/verify.sh --no-scenes # 빌드·설치·측정만 (묻지 않음 — 에이전트가 대신 돌릴 때)
scripts/device/verify.sh --scenes-only               # 장면만 다시 보기
```

- 측정: 스카이런을 자동 조종으로 날며 1초마다 FPS·가장 느린 프레임·메모리·발열 상태를
  `Documents/perf.csv` 에 기록(`PerfProbe`, `-TFPerfProbe YES` 일 때만 동작)하고 요약을 출력한다.
  통과 기준: **FPS 하위 5% ≥ 55, 메모리 < 250MB, 발열 'serious' 미만.**
  iPhone XS 는 목표 기기(iPhone 12)보다 느리므로 여기서 통과하면 여유가 있는 것이다.
- 빌드는 Debug(자동 조종·장면 스위치가 Debug 전용)지만 `-O` 로 최적화해서 Release 와 비슷하다.
- 장면: 홈 · 캐릭터 선택 · 루트 맵 · 오늘의 코스(뒷모습/앞모습) · 스카이런 · 결과 · 일시정지 ·
  명소 · 무지개 · 축제 · 설정 · 앨범 · 상점. 잘림·겹침·화면 밖 버튼·뒤집힌 화면을 본다.

## 2. 손으로 해보기 (오너, 20–30분)

자동화할 수 없는 것. 각 항목에 ✅ / ⚠️(메모) 로 기록.

| H4 | 소리 | 월드 7곳 음악 각각 1분 — 루프 이음새 끊김, 듣기 좋은지, 효과음·탈것 소리 크기, 무음 스위치·음소거 |

## 3. 판정

- 1단계 수치 미달 또는 H1·H2·H9 에 ⚠️ → 출시 전 수정이 먼저.
- H4 가 "별로" → `docs/VISUAL_AUDIO_PLAN.md` 의 오디오 트랙을 앞당긴다.
- H10 에서 5분을 못 넘기면 가격 논의보다 첫 1분 경험(온보딩·첫 코스) 개선이 먼저.
