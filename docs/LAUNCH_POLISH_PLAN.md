# 출시 마감 계획 — 검증 재실행 + 캐릭터 디자인 개선

작성 2026-11-20 · 브랜치 `release/voice-callouts-us-launch`

이 문서는 세션이 끊겨도 이어서 작업할 수 있게 만든 **단일 진행표**다.
새 세션은 아래 "이어서 하는 법"부터 읽고, 진행표에서 첫 번째 미완료
항목을 잡는다. 단계를 끝낼 때마다 진행표의 상태와 맨 아래 작업 로그를
갱신한다.

## 이어서 하는 법

1. `git status` 로 작업 트리 확인 (오너가 승인하기 전에는 커밋하지 않는다 — 미커밋 상태가 정상).
2. 아래 진행표에서 `[ ]` 인 첫 항목의 "완료 기준"을 읽는다.
3. 캐릭터 작업은 `python3 scripts/characters/generate.py` (SVG 생성) →
   `bash scripts/build_assets.sh` (PDF/PNG/아틀라스) 순서. 미리보기는
   `python3 scripts/characters/preview.py` → `build/character-preview/`.
4. 끝나면 `scripts/preflight.sh` 가 exit 0 인지 확인.

고정 규칙 (바꾸지 말 것)
- 미국 스토어만, 심사 통과 후 자동 출시. Stripe 같은 결제 없음.
- 음성 클립 실제 생성은 오너 터미널에서만 (`scripts/audio/generate_voice.sh`). 에이전트는 `--dry-run` 만.
- 실기기 빌드용 서명 값(`DEVELOPMENT_TEAM`)은 명령줄 인자로만 넘기고 `project.yml` 에 커밋하지 않는다.
- 캐릭터 PNG/PDF 는 직접 고치지 않는다. 원본은 `scripts/characters/` 의 생성기.

## 트랙 B — 캐릭터 디자인 개선 (A 와 병렬)

현재 문제 (2026-11-20 진단)
- 거북이에 등껍질이 안 보여 초록 공처럼 보인다. 여섯 캐릭터 모두 "원 두 개 + 눈" 구조라 실루엣이 비슷하다.
- 전부 단색 평면 — 명암, 하이라이트, 그림자가 없어 밋밋하다.
- 얼굴 비율이 캐릭터마다 달라 한 게임의 식구처럼 안 보인다.
- **비행 중에는 탈것이 안 보인다.** 인게임 아틀라스 4칸이 서 있는 포즈라서, 탈것을 골라도 화면에서는 꼬리 파티클만 달라진다.

디자인 방향
- 큰 머리 + 작은 몸(2.5등신), 굵고 둥근 외곽선, 2단 명암(밝은 면 + 부드러운 그림자) + 광택 하이라이트. 아이는 귀엽게, 어른은 "잘 만든 스티커"로 느끼게.
- 캐릭터마다 실루엣만 봐도 구분되는 특징 하나를 크게:
  - Turbo(거북이): 큰 돔 등껍질(육각 무늬) + 조종사 고글 + 빨간 스카프
  - Pip(펭귄): 하늘색 턱시도, 삐죽 머리깃, 위로 든 날개, 벌린 부리
  - Nutty(햄스터): 짝짝이 볼주머니, 동그란 귀, 손에 든 해바라기씨
  - Mochi(고양이): 반쯤 감은 눈, 뾰족 귀, S자 꼬리, 방울 목걸이
  - Bounce(개구리): 머리 위로 튀어나온 눈, 얼굴 너비 미소, 물갈퀴
  - Hoppy(토끼): 긴 귀(한쪽 접힘), 귀 뒤 꽃, 솜꼬리, 하트 가슴털
- 팔레트는 `docs/CHARACTER_DESIGN_PROMPT.md` 의 캐릭터별 5색을 유지하고 명암용 중간색만 추가한다 (꼬리 파티클·UI 색과 계속 맞도록).
- 표정 4종(default/joy/scared/speed)은 눈·입·소품이 함께 바뀌게 해서 작은 화면에서도 구분되게 한다.

오너가 정해야 할 것
1. **실제 명소를 그대로 쓸지, "명소풍" 가상 장소로 할지.** 조사 결과: 에펠탑 야간 조명은 운영사가 권리를 주장, 시드니 오페라하우스·할리우드 사인은 상표/라이선스 주장이 있음. 피라미드·남산 같은 곳도 종교·국가 상징은 조심해야 함. 권장: 낮 풍경의 "명소풍" 디자인 + 가상 이름(법률 자문 아님).
2. 1.0 출시에 포함할지, 1.1 업데이트로 할지. 권장: 지금 준비된 1.0 을 먼저 내고 월드는 1.1 (심사 재제출 필요 없이 일정 분리).
3. 첫 월드 2개 선택.

```bash
  build/device-dd/Build/Products/Debug-iphoneos/TurtleFlight.app

xcrun devicectl device process launch --device 40159E23-B6B4-59A7-8A35-93CA679DF10B \
  com.turtleflight.app -- -TFScreenshot daily
```

## 오너 실기기 체크리스트

자동으로 확인할 수 없어 오너가 실기기에서 봐야 하는 항목:

1. **조작감** — 기기를 기울였을 때 캐릭터가 바로 따라오는지 (Easy / Normal / Expert 각각). 보정(Calibrate) 후 중립이 맞는지.
2. **소리** — 배경음·효과음 크기, 음소거 버튼, 음성 콜아웃(클립 생성 후), 무음 스위치 상태에서의 동작.
3. **진동** — 링 통과·충돌·부스트 햅틱.
4. **성능** — 비행 중 끊김이 없는지, 5분 이상 비행해도 뜨거워지거나 느려지지 않는지.
5. **새 캐릭터** — 비행 화면에서 캐릭터 크기(이전의 2.5배)가 링을 가리지 않는지, 표정이 상황에 맞게 바뀌는지 (평소 기본 / 링 통과 기쁨 / 충돌 놀람 / 부스트 스피드).
6. **화면** — 홈·캐릭터 선택·스테이지 선택·일시정지가 잘리지 않는지 (가장 작은 기기 포함).
7. **iPad 세로** — 세로로 들면 레터박스로 나오는 것이 괜찮은지.
8. **중단 복귀** — 전화·홈 버튼 후 돌아왔을 때 일시정지 상태로 이어지는지.
9. **옵트인 기능** — Game Center, iCloud 동기화, 알림, 녹화가 설정에서 켰을 때만 동작하는지.
