# App Store copy — de

Paste into App Store Connect → App Information / Version Information
for the `de` localization. Limits: name 30, subtitle 30, promotional
text 170, keywords 100 (comma-separated, no spaces after commas),
description 4000, what's new 4000.

## Name (≤30)
Turtle Flight

## Subtitle (≤30)
Neigen, fliegen, treffen

## Promotional text (≤170)
Neu: Kurs des Tages — 12 Ringe, für alle derselbe Kurs. Wie nah kommst du an die Mitte?

## Description
Tiere, die nicht fliegen können, fliegen trotzdem. Neige dein Handy und steuere eine Schildkröte im Panzer-Jet, einen Pinguin im Bauchgleitflug, einen Hamster im Kugel-Kopter, eine Katze auf dem Zauberbesen, einen Frosch mit Ballonkörper oder einen Hasen mit Ohren-Rotoren — und fliege durch die Ringe.

SAUBER DURCH
Jeder Ring bewertet dich: VOLLTREFFER, SUPER, OK oder VORBEI, je nachdem, wie nah an der Mitte du fliegst. Reihe Treffer zu einer Combo. Ringe schrumpfen, wenn du zögerst, kippen zu Schlitzen und driften zur Seite.

KURS DES TAGES
Ein Kurs pro Tag, aus dem Datum erzeugt, für alle Spieler weltweit gleich. Schlag deinen eigenen Geist — dein bester Flug fliegt neben dir.

SKY RUN
Ein endloser Kurs, der enger wird, je weiter du kommst. Drei Fehlschüsse und Schluss. Noch einmal.

AUF DEINE ART
Drei Empfindlichkeitsstufen, von einem sanften, sich selbst ausrichtenden Easy bis zu einem Expert-Modus mit echter Geschwindigkeit und Strömungsabriss. Boost ist eine Anzeige, die Sterne auffüllen.

KOMM MORGEN WIEDER
Drei Tages-Quests, eine Tagesserie, Meisterschaftsstufen pro Figur und Schweifarben, die du dir verdienst.

STANDARDMÄSSIG PRIVAT
Kein Konto. Keine Werbung. Kein Tracking. Game-Center-Bestenlisten, tägliche Erinnerung, iCloud-Sync und Clip-Teilen sind aus, bis du sie einschaltest.

Ab 4 Jahren. Querformat. Gyroskop erforderlich (iPhone; auf iPads ohne Gyroskop wird per Wischen gesteuert).
