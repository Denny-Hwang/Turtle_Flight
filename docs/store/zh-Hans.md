## Description
不会飞的动物，照样飞上天。倾斜手机，操控坐着龟壳喷气机的乌龟、用肚子滑翔的企鹅、球形直升机里的仓鼠、骑魔法扫帚的猫、气球身体的青蛙、耳朵螺旋桨的兔子，穿过一个个门环。

干净利落地穿过
每个门环都会评判你：按离中心的距离判定正中、很棒、通过或错过。连续通过累积连击。犹豫时门环会缩小，会倾斜成缝隙，也会左右漂移。

今日航线
每天一条，由日期生成，全世界玩家完全相同。与你最佳成绩的幽灵并肩飞行，战胜自己。

天空长跑
越飞越窄的无尽航线。错过三次即结束。再来一次。

按你的方式飞
三档灵敏度：从温和自动回正的 Easy，到有真实空速与失速的 Expert。加速是靠星星充能的槽。

明天再来
每日 3 个任务、连续天数、角色熟练度，以及靠实力赢得的尾迹颜色。

默认私密
无账号，无广告，无追踪。Game Center 排行榜、每日提醒、iCloud 同步和片段分享全部默认关闭，由你决定是否开启。

4+ 岁。横屏。需要陀螺仪（iPhone；无陀螺仪的 iPad 可拖动操控）。
