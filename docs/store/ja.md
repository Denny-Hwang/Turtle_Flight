## Name (≤30)

## Subtitle (≤30)
傾けて飛ぶ。リングの真ん中を抜けろ

## Promotional text (≤170)
新登場「今日のコース」— 1日1つ、世界中みんな同じ12ゲート。中心にどこまで近づける？

## Description
飛べない動物たちが、それでも飛ぶ。スマホを傾けて、甲羅ジェットのカメ、腹ばい滑空のペンギン、ボールコプターのハムスター、魔法のほうきのネコ、風船ボディのカエル、耳コプターのウサギを操り、リングを抜けよう。

きれいに抜ける
すべてのリングが判定する。中心への近さで「ど真ん中」「グレート」「OK」「ミス」。連続で抜けてコンボ。リングはためらうと縮み、スリットに傾き、横に揺れる。

今日のコース
1日1つ、日付から生成され、世界中のプレイヤーに同じコース。自分のベストのゴーストと並んで飛び、自分に勝とう。

スカイラン
進むほど狭くなるエンドレスコース。3回ミスで終了。もう1回だけ。

自分のやり方で
やさしく自動水平のEasyから、本物の速度と失速があるExpertまで3段階の感度。ブーストは星で満たすゲージ。

明日もまた
毎日3つのクエスト、連続記録、キャラクター熟練度、自分で手に入れるトレイルカラー。

はじめからプライベート
アカウントなし。広告なし。トラッキングなし。Game Centerランキング、1日1回の通知、iCloud同期、クリップ共有はすべて自分でオンにするまでオフ。

4歳以上。横向き。ジャイロスコープが必要（iPhone。ジャイロのないiPadはドラッグ操作）。
