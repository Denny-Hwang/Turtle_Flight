## 1. 조종 범위 (☑ 이번 PR)

원인: 축 하나에 데드존 8/4/1.5°, 최대 기울기 25/35/50°, 그 위에 3차/2차 곡선. Easy 에서 8° 기울여도 상승 0,
15° 기울여도 최대의 7%. 그래서 화면이 안 보일 만큼 눕혀야 했다.

수정: 조향과 상승을 따로 (`AxisResponse`).

| | 조향 데드존 / 최대 / 곡선 | 상승 데드존 / 최대 / 곡선 | 최대 상승속도 |
|---|---|---|---|
| Easy | 3° / 18° / x^1.6 | 2.5° / 12° / x^1.4 | 40 m/s (전 30) |
| Normal | 2° / 20° / x^1.4 | 2° / 12° / x^1.25 | 70 m/s (전 60) |
| Expert | 1° / 25° / 선형 | 1° / 15° / 선형 | 120 m/s |

이제 8° 만 숙여도 상승 입력이 40% 이상. 실기기에서 너무 예민하면 `SensitivityProfile` 의 `fullTilt` 를
2–3° 씩 늘리면 된다.

## 2. 터치 조이스틱 (기획)

### 지금 있는 것
설정 → 조작 → "터치로 조종" (기본 꺼짐). 화면 아무 데나 드래그, 보이는 UI 없음, 화면 절반을 끌어야 최대.
알려진 버그 두 개:
- 손을 떼도 마지막 입력의 85–92% 가 남아 계속 돈다. 해제 시 감쇠가 한 번만 일어나기 때문.
- 손가락을 멈추고 있으면 입력이 목표값까지 안 올라간다. 스무딩이 손가락이 움직일 때만 진행되기 때문.

### 제안: 떠 있는 조이스틱 (floating stick)

| # | 항목 | 내용 |
|---|---|---|
| J1 | 선행 버그 수정 | 터치 입력을 "목표값"으로 저장하고 매 프레임 스무딩한다. 떼면 0.15초 안에 0으로 돌아오고, 자동 수평화도 동작한다 |
| J2 | 조이스틱 UI | **오른쪽 화면 아래 절반 어디든** 엄지를 대면 그 자리에 생긴다. 받침 120pt, 손잡이 56pt, 최대 이동 60pt. 떼면 손잡이가 스프링처럼 돌아오고 받침은 사라진다. 부스트는 지금처럼 왼쪽 아래 |
| J3 | 매핑 | 좌우 = 회전, 위 = 상승 / 아래 = 하강 (아이 기준 직관). 설정에 "상하 반전" (비행기식). 곡선은 레벨별 `AxisResponse` 그대로, 데드존은 반지름의 10% |
| J4 | 조작 방식 3가지 | 설정 → 조작: **기울이기** (기본) / **조이스틱** / **섞어서** (좌우는 기울기, 위아래는 엄지). "섞어서"는 1번 문제(앞뒤로 숙이면 화면이 안 보임)를 근본적으로 없앤다 |
| J5 | 처음 고르기 | 온보딩 마지막에 "기울여서 날래요 / 손가락으로 날래요" 두 카드. 보정 카드에도 작은 "손가락으로 할래요" 링크 |
| J6 | 마무리 | 최대 이동 시 가벼운 햅틱 (`Haptics.shared`), 왼손잡이용 좌우 바꾸기, VoiceOver 라벨, iPad 는 `.deviceCanvas()` 규칙대로 |

테스트로 고정할 것:
- 떼면 0으로 돌아간다.
- 같은 기울기와 같은 조이스틱 이동이 같은 입력을 낸다.
- 조이스틱 모드에서는 보정을 건너뛴다.
- 섞어서 모드에서는 기울기의 앞뒤 값을 무시한다.

규모: J1–J3 하루, J4–J6 하루.
⏸ **오너 결정:** 기본 상하 방향(위 = 상승 권장), "섞어서" 모드를 넣을지 (권장).

## 3. 링 코스와 길 안내

### 3.1 이번에 고친 것 (☑)
"링 없는 구간"의 원인은 세 가지였다.

1. **다시 하기 · 다음 코스가 이전 비행이 끝난 자리에서 시작했다.**
   - 코스는 늘 원점에서 북쪽으로 깔리는데, 캐릭터는 수 km 떨어진 곳에 있었다. 그래서 새 링이 안 보였다.
   - → `placeAtCourseStart()`: 매 스테이지 시작마다 원점으로 돌린다. 첫 링 높이에 맞추고, 첫 링을 바라보게
     하고, 카메라도 같이 옮긴다.
   - 덤: 첫 링이 시야 아래 62° 에 있던 Valley Run 도 해결.
2. **링을 놓치면 목표가 그 링에 그대로 남았다.**
   - 이미 지나친 링이라 목표가 뒤에 있었고, 앞의 링들은 세지 않았다. Sky Run 은 목숨만 깎이고 뒤로 돌아가야 했다.
   - → 놓치거나, 멀리 비켜 지나가거나, 80 m 넘게 지나치면 MISS 로 세고 다음 링으로 넘어간다.
   - 대신 링을 절반 넘게 놓치면 실패("링을 절반 넘게 놓쳤어요"). 놓친 링이 있으면 별은 최대 2개, 4분의 1을
     넘게 놓치면 1개. Kids 는 그대로 실패 없음.
3. **자유 비행 "별 사막".**
   - 첫 별 무리에서 멀어지면 남은 별 3개 이상이 거기 버려졌다. 그래서 개수가 "부족"으로 읽히지 않아 새 별이
     영영 안 나왔다.
   - → 700 m 넘게 멀어진 별은 정리하고, 새 무리는 진행 방향 250 m 앞에 만든다.

그리고 **화면 가장자리 링 안내** (`RingGuideIndicator`):
- 목표 링이 화면 밖에 있으면 그쪽 가장자리에 금색 화살표와 거리(10 m 단위)를 띄운다. 위나 아래에 있으면
  위아래 가장자리에 뜬다.
- 뒤에 있으면 돌아야 할 쪽 아래에 "뒤에 있어요".
- 40 m 안이거나 화면 안에 보이면 숨긴다.

## 4. 길목 볼거리 — "30초마다 새로운 것" (기획)

### 지금 상태
- 장식은 200 m 조각마다 해시로 깔린다(구름·나무·새 등). 대부분 **출발 고도 500 m 보다 아래**에 있어 내려다보게
  되고, 비슷한 것이 계속 반복된다.
- 명소는 1.2 km 칸마다 1개, 하늘의 신비는 비행당 35% 확률로 1번이다.
- 그래서 "다음엔 뭐가 나올까" 하는 기대가 약하다.

### 제안: 길목 세트피스 (set piece)
맵 전체를 촘촘히 만들지 않고, **플레이어가 가는 길 앞에** 특색 있는 조형물이나 아이템을 하나씩 놓는다.

- **리듬:** 순항 기준 25–35초마다 하나, 진행 방향 앞 400–600 m, **플레이어 고도 근처**(눈높이에서 보이게).
  명소와 겹치면 건너뛴다.
- **종류 세 가지:**
  - **통과형** — 지나가며 감상: 아치, 터널, 문
  - **상호작용형** — 닿으면 효과: 상승기류, 바람 고리, 선물 풍선
  - **동행형** — 잠깐 옆에서 같이 난다: 새 편대, 고래 구름
- **월드별 후보** (전부 오리지널, 실존 명소 재현 금지 규칙 유지):

| 월드 | 통과형 | 상호작용형 | 동행형 |
|---|---|---|---|
| sky | 무지개 아치 · 구름 터널 | 상승기류 기둥(살짝 들어 올림) · 선물 풍선(터뜨리면 간식) | 기러기 V 편대 |
| desert | 모래바람 고리 · 거대 선인장 문 | 신기루 오아시스(별 무리) | 연 날리는 카라반 |
| city | 줄지어 걸린 만국기 · 빨래줄 다리 | 비눗방울 분수(통과 시 반짝) | 비둘기 떼 |
| seoul | 연등 터널 · 기와 지붕 문 | 연(鳶) 줄 바람 고리 | 까치 둘 |
| wild | 폭포 아치 · 쓰러진 고목 다리 | 반딧불 무리(별 대신) | 독수리 |
| space | 고리 행성 사이 통과 · 별자리 문 | 혜성 꼬리(타면 부스트) | 작은 위성 |
| ocean | 고래 물기둥 아치 · 산호 문 | 거품 기둥(상승) | 돌고래 무리 |

- **기술:**
  - `LandmarkFactory` 처럼 SceneKit 기본 도형으로 만든다.
  - 동시에 최대 2개, 지나가면 재활용(풀).
  - 하나당 정적 지오메트리 평탄화로 그리기 호출 ≤ 3.
  - iPhone XS 에서 60 FPS 측정 (`verify.sh --no-scenes`).
- **수집:** 처음 본 세트피스는 앨범 "하늘 도감" 에 도장(기존 엽서 시스템 재사용). 다 모으면 보상.

| # | 단계 |
|---|---|
| ☑ W1 | 스포너와 리듬 (앞쪽 배치, 고도 맞춤, 명소 회피, 최대 2개) + 테스트 — `SetPieceScheduler`: 첫 12–18초, 이후 25–35초 간격, 420–560 m 앞, 같은 것 연속 금지. 지나친 것은 450 m 뒤에서 정리 |
| ☑ W2 | 1차 묶음: 월드당 3개(통과형 2 + 상호작용형 1) = 21개 — `SetPiece`, `SetPieceFactory`. 정지 부분은 재질별 한 메시로 굽는다(`bake`, `PropMesh` 재사용). 서울 기와 문은 신사 문처럼 보이지 않게 한옥풍으로 |
| ☑ W3 | 상호작용 효과와 햅틱 · 효과음 — 통과 +1★, 상승기류는 초당 30 m(속도는 그대로), 부스트 50% 충전, 별 묶음 +3★. 처음 보면 "새 볼거리" 배너(`SetPieceLog`). 간식 대신 별 |
| ☑ W4 | 동행형 — 2026-11-27 `Companion` / `CompanionFlight` / `CompanionFactory`. 월드마다 한 무리(기러기 V자 · 모래새 · 비둘기 · 까치 · 독수리 · 꼬마 위성 · 돌고래). 첫 등장 40–70초, 이후 70–110초마다. 앞에서 날아와 옆 26 m 자리에서 12초 같이 날고 바깥 위로 떠남. 20 m 안으로 붙으면 +1★. 매 프레임 갱신(렌더 스레드), 하늘의 신비와 겹치면 미룸 |
| ☑ W5 | 하늘 도감 — 2026-11-27 앨범 맨 아래 "하늘 도감": 월드별 3칸, 본 것은 효과 아이콘 + 이름. 한 월드 3개 다 보면 +3★, 21개 전부 +15★ (자유 비행 결과에서 엽서 마일스톤과 함께 지급, `claimedPostcardRewards` 에 `setpiece.` 아이디로 기록 → 저장 필드 추가 없음) |
| ◐ W6 | 실기기 FPS · 멀미(H2) 확인 — 2026-11-27 FPS ☑: 자유 비행 3분(`verify.sh --free`) 하위5% 59 fps · 최악 33 ms · 128 MB (미리 만들기 + 명소 풀 PR #72 후). 멀미(H2) 는 오너 손 확인 대기 |

⏸ **오너 결정:**
- 1차 21개 목록을 위 표에서 골라 주거나, 그대로 진행.
- 상호작용형을 미션 코스에도 넣을지. 권장은 자유 비행만 — 미션은 링에 집중.

## 5. BGM 다채롭게 (기획)

### 지금 상태 (원인)
- 월드당 곡 1개, 37–53초 루프 하나가 비행 내내 반복된다. 메뉴 음악은 없다.
- 8코드 진행이 그대로 돌고, 섹션(인트로 · 후렴 · 브리지)이 없다.
- 멜로디 생성기가 2마디 동기를 그대로 복사한다.
- 드럼·베이스 패턴이 매 마디 같다.
- 볼륨 변화 없이 정규화되어 있다.
- 7곡을 한 생성기가 만들어 결이 비슷하다.
- 상황에 따라 바뀌는 것(부스트·콤보·시간 임박)이 없다.

### 제안

| # | 항목 | 내용 |
|---|---|---|
| M1 | 곡 구조 | 인트로 4 → A 8 → A′ 8(멜로디 변주) → **B 8(다른 코드 · 리드 악기 교체)** → 브레이크 4(드럼 빠짐) → A″ 8 → 루프. 곡당 약 2분 (지금 40초) |
| M2 | 멜로디 생성기 | 동기 발전(반복 대신 이동 · 뒤집기 · 리듬 변형), 묻고 답하기 구조, 섹션마다 음역 바꾸기 |
| M3 | 다이내믹 | 4마디마다 필인, 드럼 변형 3종, 섹션별 악기 빼고 넣기, B 에서 크레셴도 |
| M4 | 상황 반응 (어댑티브) | 곡을 "기본" + "에너지" 두 스템으로 렌더해 AVAudioEngine 으로 샘플 단위 동시 재생. 콤보 3+·부스트에 에너지 층이 페이드인, 남은 시간 10초에는 긴장 층, 클리어·실패 짧은 징글, 일시정지 시 로우패스 필터 |
| M5 | 곡 수 | 월드별 **자유 비행용(잔잔)** / **미션용(경쾌)** 2곡 + 홈 화면 테마 1곡 + 결과 징글 2개 = 17곡 |
| M6 | 월드 음색 | 월드마다 대표 악기 하나씩 새로 합성: 바다 스틸드럼풍, 도시 아코디언풍, 서울 해금풍 찰현, 우주 글래스 하모니카풍, 사막 우드풍, 야생 칼림바풍, 하늘 오카리나풍 |

- **제약:**
  - 지금처럼 전부 오프라인 합성(`scripts/audio/render_assets.swift`). 에이전트와 CI 에서 재생성 가능.
  - 샘플과 생성형 음악 모델(Lyria 등)은 쓰지 않는다.
- **용량:** 2분 × 14곡 × 112 kbps ≈ 23 MB + 에너지 스템 ≈ 8 MB. 앱 22 MB → 약 53 MB 로 80 MB 예산 안.

- **순서:** M1+M2+M3 (같은 곡이 덜 지루해짐, 용량 거의 그대로) → 오너 귀 검수 → M5 → M6 → M4.
