# 지형 · 랜드마크 · 비주얼 · 소리 업데이트 계획

작성 2026-11-22. 2026-11-22 품질 리뷰의 결론("기술 완성도는 출시 가능, 비주얼·사운드는 유료
경쟁작 아래, 체감 품질 미검증")에 대한 개선 계획이다. **`docs/DEVICE_VERIFICATION.md` 를
먼저 끝낸 뒤** 진행하며, 실기기 결과(특히 FPS 여유와 H4 소리 평가)에 따라 순서를 조정한다.

## 이어서 하는 법

1. 진행표에서 첫 번째 ☐ 단계를 잡는다. 단계마다 독립 PR.
2. 바꾸기 전에 같은 장면을 캡처해 두고(아래 "비교 캡처"), 바꾼 뒤 같은 장면과 나란히 본다.
3. 렌더링을 건드린 단계는 `scripts/device/verify.sh` 로 실기기 FPS 를 다시 잰다. 하위 5% FPS 가
   55 아래로 떨어지면 그 단계는 머지하지 않는다.

비교 캡처: `-TFScreenshot freeflight` (월드 7개 × 낮/노을), `tour` (사막·서울),
`daily` · `skyrun`. 같은 시드라 매번 같은 장소가 나온다. `tour` 에 `-TFTourKind <rawValue>`
(예: `palaceGate`, 해당 월드 선택 필요) 를 주면 그 랜드마크만 나온다.

랜드마크 갤러리(V6–V8 용): 랜드마크마다 두 각도 렌더 PNG 를 만든다(검사 아님, 기본 skip).

```bash
TEST_RUNNER_TF_GALLERY=$PWD/build/gallery xcodebuild test -project TurtleFlight.xcodeproj \
  -scheme TurtleFlight -destination 'platform=iOS Simulator,name=iPhone 17' \
  -only-testing:TurtleFlightTests/LandmarkGalleryTests
# 일부만: TEST_RUNNER_TF_GALLERY_KINDS="palaceGate shipwreck"
```

## 지금 상태 (코드에서 확인한 원인)

| 보이는 문제 | 원인 |
|---|---|
| 지형이 납작하고 얼룩져 보인다 | 지형 정점 법선이 전부 `(0,1,0)` → 경사 명암이 없다 (`TerrainGenerator.generateChunk`) |
| 색이 줄무늬처럼 끊긴다 | 높이별 색이 계단식(`WorldProfile.color(forHeight:)`), 섞임·경사·변화 없음 |
| 물이 물 같지 않다 | 물 표면이 따로 없고, 0m 아래 지형을 파랗게 칠한 것뿐 |
| 하늘이 밋밋하다 | `scene.background` 가 단색 + 안개. 그라데이션·구름층·지평선 빛 없음 |
| 랜드마크가 블록 장난감 같다 | 원통·상자·구 조합 + 단색 재질, 가장자리 강조·그라데이션·디테일 없음 |
| 캐릭터가 스티커처럼 떠 있다 | 빌보드라 선회해도 기울지 않음, 화면 높이 약 13% |
| 소리 품질 미확인 | 오프라인 합성 음원(2026-11-22), 사람이 들어본 적 없음, 음성 콜아웃 0/9 |

## 하지 않을 것 / 결정 필요

- **모델 파일(USDZ) 도입 여부 — 오너 결정.** 지금 원칙은 "랜드마크는 SceneKit 기본 도형, 모델 파일
  없음, 명소풍 오리지널"이다. V6–V7 로도 부족하면 Blender 로 직접 만든 저폴리 모델 도입을 검토한다
  (앱 크기 여유 약 59MB). 외부 에셋 팩은 라이선스·"실존 명소 재현" 문제 때문에 쓰지 않는다.
- 셰이더는 SceneKit shader modifier 범위에서만 (Metal 커스텀 파이프라인은 하지 않음).
- 실존 건축물을 더 닮게 만드는 방향은 하지 않는다 (CLAUDE.md 월드 투어 원칙).
