# 루트 · 난이도 · 보상 · 햅틱 · 시크릿 코드 계획 (2026-11-20)

오너 요청(2026-11-20)을 기능 단위로 나눈 설계 + 진행표. 세션이 끊겨도 이 문서의
진행표만 보고 이어갈 수 있게 유지한다. 브랜치: `feature/routes-rewards`.

## 이어서 하는 법
1. `git checkout feature/routes-rewards && xcodegen generate`
2. 아래 진행표에서 첫 번째 미완료(☐) 단계부터 진행
3. 단계가 끝나면 `scripts/preflight.sh` 통과 확인 → 진행표 갱신 → 커밋

## 진행표
| 단계 | 내용 | 상태 |
|---|---|---|
| P1 | 햅틱 매니저 + 이벤트별 진동 패턴 + 설정 토글 | ☑ |
| P2 | 루트 5개 / 코스 21개, 월드별 링 개수·크기, 잠금 해제 규칙, 루트 맵 화면 | ☑ |
| P3 | Kids 난이도 (가장 쉬움, 실패 없음) | ☑ |
| P4 | 보상: 별 지갑 + 캐릭터별 간식, 상점, 결과 화면 보상 표시 | ☑ |
| P5 | 시크릿 코드 5개 (입력 화면, 1회 사용, 해시 저장) | ☑ |
| P6 | 7개 로케일 문자열, 테스트, 문서(CHANGELOG/CLAUDE.md/PRIVACY), 시뮬레이터 캡처 검수 | ☑ |

## 1. 루트 (병렬 path)
월드를 한 줄로 잇지 않고 **루트 5개**로 나눈다. 루트 4개는 첫 코스가 처음부터
열려 있고, 같은 루트 안에서는 앞 코스를 클리어해야 다음 코스가 열린다.

| 루트 | 월드 | 코스 (stage index) | 처음 상태 |
|---|---|---|---|
| Sky School | sky | 기존 캠페인 5개 (0–4) | 첫 코스 열림 |
| Sun Road | desert → city | 4개 (10–13) | 첫 코스 열림 |
| East Trail | seoul → wild | 4개 (20–23) | 첫 코스 열림 |
| Deep Blue | ocean | 4개 (30–33) | 첫 코스 열림 |
| Star Road | space | 4개 (40–43) | **잠김** — 다른 4개 루트의 마지막 코스를 모두 클리어하면 열림. 시크릿 코드로 즉시 열 수 있음 |

- 기존 캠페인 5개(0–4)의 코스·저장 기록·고스트는 그대로 둔다 (index 유지).
- 루트 코스는 월드가 고정된다 (Sky School 만 기존처럼 월드 선택 가능).
- 잠긴 "다음 코스"는 별로 미리 열 수 있다 (§4). Star Road 는 별로 못 연다.
- 코스 정의는 `RouteCatalog` 한 곳에 데이터로 둔다. 이름은
  `"<월드 이름> <번호>"` 포맷이라 코스별 번역 문자열이 필요 없다.

### 월드별 난이도 (링 개수 · 반지름)
뒤로 갈수록 링이 많아지고 작아진다. 제한 시간 = 링×12초, ★3 시간 = 링×5+10초.

| 코스 | 링 | 반지름 | 게이트 |
|---|---|---|---|
| Sun Road 1 (desert) | 8 | 45 | 기본 |
| Sun Road 2 (desert) | 10 | 38 | 줄어드는 링 |
| Sun Road 3 (city) | 10 | 32 | 기울어진 링 |
| Sun Road 4 (city) | 14 | 26 | 혼합 |
| East Trail 1 (seoul) | 8 | 42 | 기본 |
| East Trail 2 (seoul) | 10 | 36 | 줄어드는 링 |
| East Trail 3 (wild) | 12 | 30 | 기울어진 링 |
| East Trail 4 (wild) | 14 | 24 | 혼합 |
| Deep Blue 1–4 (ocean) | 9 / 11 / 12 / 16 | 40 / 34 / 28 / 22 | 기본 → 혼합 |
| Star Road 1–4 (space) | 12 / 14 / 16 / 20 | 30 / 26 / 22 / 18 | 혼합, 마지막은 콤보 축소 |

## 2. Kids 난이도
루트 맵 화면과 설정에서 켜는 전역 토글 (`PlayerProgress.kidsMode`, 기본 OFF).
조종 민감도(Easy/Normal/Expert)와는 별개다.

켜면 모든 루트 코스가 Kids 버전으로 바뀐다:
- 링 반지름 ×1.6 (최소 45), 링 개수 ×0.6 (최소 4)
- 특수 게이트(줄어듦/기울어짐/움직임) 없음, 콤보 축소 없음
- **제한 시간 없음 → 실패 없음**
- 링을 빗나가도 되돌아갈 필요 없이 다음 링으로 넘어감 (건너뛴 링은 통과 수에서 빠짐)
- 지형 접촉은 별에 영향 없음
- 별: 건너뛴 링 0개 ★3, 절반 이하 ★2, 그 외 ★1 — 항상 클리어
- Kids 클리어도 다음 코스 잠금 해제·보상에 반영. 단 기록은 `kidsResults` 에 따로 저장 —
  캠페인 별(`totalStars`, Game Center 순위, 트레일 단계)에는 일반 모드 기록만 들어간다
- 오늘의 코스 / 스카이런(공용 순위)은 Kids 영향 없음. 고스트는 `-kids` 키로 분리

## 3. 햅틱
`Haptics` 한 곳에서 이벤트 → 패턴을 정한다. 설정에 "진동" 토글 (기본 ON,
`haptics.enabled`). 여기저기 흩어진 `UIImpactFeedbackGenerator` 호출을 모두 교체.

| 이벤트 | 패턴 |
|---|---|
| 링 정중앙(BULLSEYE) | 단단한 강한 탭 + 짧은 여운 |
| 링 GREAT / OK | 중간 탭 / 가벼운 탭 |
| 링 테두리에 부딪힘 (살짝 벗어남) | 묵직한 두 번 툭툭 |
| 링 완전히 빗나감 | 경고 진동 |
| 땅에 부딪힘 | 가장 강한 쿵 + 잔진동 두 번 |
| 부스트 시작 / 게이지 부족 | 중간→부드러운 상승 / 가벼운 탭 |
| 별·간식 획득, 명소 발견, 인사 | 부드러운 탭 / 성공 알림 |
| 코스 클리어 / 실패 | 성공 알림 / 오류 알림 |
| 구매 성공, 코드 성공 / 실패 | 성공 / 오류 |

## 4. 보상
두 가지 화폐. 인앱 결제는 없다 — 전부 플레이로만 얻는다.

**별 (공통)** — "별 지갑" (`starsBanked − starsSpent`).
- 얻는 곳: 코스 첫 클리어·최고 기록 갱신 시 받은 별 수만큼, 그 외 재도전은 1개 (쉬운 코스 반복 방지),
  퀘스트 보상, 시크릿 코드
- 기존 트레일 색 단계(누적 별 기준)는 그대로. 지갑을 써도 다시 잠기지 않는다
- 기존 플레이어는 지금까지 모은 별이 지갑 시작 금액이 된다

**간식 (캐릭터별)** — 그 캐릭터로 비행해야 쌓인다.
| 캐릭터 | 간식 |
|---|---|
| Turbo 거북이 | 🥬 상추 |
| Pip 펭귄 | 🐟 물고기 |
| Nutty 햄스터 | 🌻 해바라기씨 |
| Mochi 고양이 | 🧶 털실 |
| Bounce 개구리 | ✨ 반딧불 |
| Hoppy 토끼 | 🥕 당근 |

- 얻는 곳: 코스 클리어 `1 + 별 수 + 불스아이 2개당 1 (최대 3)`, 자유 비행 별 3개당 1 (최대 6),
  스카이런 링 5개당 1 (최대 8), 시크릿 코드

**살 수 있는 것 (화폐별로 다름)**
| 화폐 | 상품 | 가격 |
|---|---|---|
| 별 | 잠긴 다음 코스 미리 열기 | 코스당 8 |
| 별 | 자유 비행 하늘 고르기: 아침 / 노을 / 밤 | 10 / 15 / 20 |
| 별 | 전 캐릭터 공용 "혜성" 트레일 | 40 |
| 간식 | 그 캐릭터 전용 트레일 3종 (반짝 / 빛 / 오로라) | 6 / 14 / 28 |

전부 꾸미기·편의 기능이고 비행 물리나 점수에는 영향이 없다.

## 5. 시크릿 코드
설정 → "시크릿 코드" 입력란 (루트 맵의 Star Road 잠금 카드에서도 진입).
대소문자·공백·기호 무시, 코드당 기기에서 1회, 오프라인 검증.

| 코드 | 보상 |
|---|---|
| 코드 A | Star Road 루트 즉시 열림 |
| 코드 B | 별 30 |
| 코드 C | 모든 캐릭터 간식 15 |
| 코드 D | 전 캐릭터 공용 "혜성" 트레일 (별 40으로도 살 수 있음 — 코드 전용 보상은 없다) |
| 코드 E | 스타터 팩: 별 10 + 모든 캐릭터 간식 5 |

- **저장소가 공개(public)라서 코드 원문은 저장소에 넣지 않는다.** 앱에는 솔트를 섞은
  SHA-256 해시만 들어간다. 원문은 오너에게 채팅으로 전달하고 gitignore 된
  `marketing/secret_codes.md` 에만 둔다.
- ⚠️ **심사 리스크 (App Review 3.1.1)**: 가이드라인은 앱이 자체 코드로 콘텐츠를
  여는 것을 제한한다. 이 앱은 결제가 전혀 없고 코드로 여는 것이 전부 플레이로도
  얻을 수 있는 것이라 위험은 낮지만 0은 아니다. 대비:
  (1) 리뷰 노트에 "무료 홍보 코드, 판매 안 함, 전부 플레이로도 획득 가능" 명시,
  (2) 리젝 시 `SecretCodes.isEnabled = false` 한 줄로 입력란을 숨길 수 있게 구현.
